# Attribution

## Mem0-related files

### answers_mem0_conv26.json

The per-question answers in `answers_mem0_conv26.json` come from a **control
run**: Mem0's open-source memory backend (`mem0ai` v2, repo pinned at commit
4b61c5d) performed ingestion and retrieval, and the final answers were
generated by **our reader with our answer prompt** over the top-15 retrieved
items. They are NOT outputs of Mem0's upstream benchmark pipeline and are not
Mem0's published answers; they are the paper's fixed-answer prompt-sensitivity
control slice.

- **Mem0 OSS dependency (backend code + ported prompt):**
  https://github.com/mem0ai/memory-benchmarks
- **License (of that code/prompt):** Apache-2.0
- **Commit pinned at time of run:** 4b61c5d

The Apache-2.0 attribution above applies to the Mem0 code and its ported
prompt, NOT to these generated answers: the `answer` text in this file is our
reader's output (MIT, see "Mnemoverse computed outputs" below), while the
`question`/`gold` fields remain LoCoMo CC BY-NC 4.0 per the mixed-license
note below.

The mem0 judge prompt in `kit/prompts/judge_mem0_generous.txt` is ported
verbatim from the same repository under the same Apache-2.0 license.

## LoCoMo dataset

The LoCoMo dataset (Long Conversational Memory) is the work of:

> Maharana, A., Lee, D., Tulyakov, S., Bansal, M., Barbieri, F., & Fang, Y. (2024).
> Evaluating Very Long-Term Conversational Memory of LLM Agents.
> ACL 2024. https://arxiv.org/abs/2402.17753

- **Dataset repository:** https://github.com/snap-research/locomo
- **License:** **CC BY-NC 4.0** (Creative Commons Attribution-NonCommercial 4.0).

**Mixed-license files.** Any file in this kit that carries LoCoMo `question` or `gold`
fields (`answers_mem0_conv26.json`, `answers_engine_conv26.json`, `mem0_oss_answers/conv*.json`, `matrix_conv26_answers.json`) is mixed content:
the LoCoMo `question`/`gold` fields are **CC BY-NC 4.0** (NonCommercial, attribution
required). The `answer` fields differ by file: in `mem0_oss_answers/conv*.json` they are
Mem0-generated and **Apache-2.0** (see above); in `answers_mem0_conv26.json` they are
**our reader's output** (control run — MIT, see below), not Mem0's. Our derived
schema/ordering is under the kit's own licence. `locomo_gold_ids.json`
carries only derived evidence IDs + category labels (no question or gold text). This is
not legal advice — it removes the attribution ambiguity of labelling a mixed file
Apache-2.0 wholesale.

### locomo_gold_ids.json

`locomo_gold_ids.json` is a **derived file**: it contains only per-question
evidence IDs (dialogue:turn references, e.g. "D1:3") and category labels
extracted from the full dataset. Category labels were derived from the integer
category codes in locomo10.json using the canonical map
`{1→multi_hop, 2→temporal, 3→open_domain, 4→single_hop, 5→adversarial}`.

No question text, no gold answers, and no conversation content are included.
