# Repo map

- `README.md` — headline results, three-command reproduction, licensing, citation.
- `REPRODUCING.md` — claim-to-command registry: which command certifies which number, at what tier.
- `CONTRIBUTING.md` — rules for proposing wording or citation edits to the paper.
- `paper/current/main.tex` — the paper (LaTeX, arXiv target). Build with `bash paper/current/build.sh` → `main.pdf`;
  `bash paper/package.sh` produces the flat, self-contained bundle.
- `paper/refs.bib` — shared bibliography (every entry field-verified against arXiv; dates in its header comments).
- `figures/` — committed figure PDFs (+ `.png`), regenerated by `scripts/make_recall_curve.py` and
  `scripts/make_crossconv_figure.py` (matplotlib needed; inputs in `scripts/figdata/` and `experiments/`).
- `kit/` — public, self-contained reproducibility kit. See `kit/README.md` and `kit/MANIFEST.md`.
  - `kit/scripts/` — `judge.py` (the judge runner), `verify_claims.py` (one-command reproduction),
    `recompute_recall.py` and `recompute_judge_error.py` (offline, no API key), `run_experiments.py`,
    `judge_error/` (FP/FN analysis + `RESULTS.md`).
  - `kit/prompts/` — every grading prompt the paper uses: lenient (Mem0's), strict (ours), our default,
    the LongMemEval port (default + temporal), the calibrated golden prompts, four single-rule ablations.
  - `kit/data/` — answers, gold ids, committed verdicts, matrix cells; `ATTRIBUTION.md` gives the license per file.
  - `kit/judge_audit/` — the author's human labels (control slice, engine side, validation set) and the label sheet.
  - `kit/annotation/` — the two-annotator relabeling campaign: tool, unblinding key, returned labels, κ analysis.
  - `kit/docs/` — asymmetry inventory, provenance contract, BEAM integrity rules, competitor-claims provenance,
    `PROVENANCE_NOTES.md` (the P1–P9 register the paper's footnotes cite).
- `experiments/` — full-run outputs behind the headline: `hardening/` (per-answer verdicts, cross-conversation
  swing, ablations, third backbone, LongMemEval rubric, rank bootstrap) and `golden_judge/` (calibrated-judge
  runs). File map in `experiments/README.md`.
- `scripts/` — figure generation and provenance scripts (`count_disagreements.py`, `stats_ci.py`,
  `per_conv_calibrated.py`, `rank_bootstrap.py`, `noise_band.py`, …); `scripts/figdata/` holds figure inputs.
  Superseded scripts are named as such in `REPRODUCING.md`.
